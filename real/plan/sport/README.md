# Sport add-on (not set up yet)

Run `/sport` in Claude Code and tell it your sport, position, season, and the skills you train (or attach your coach's program). It will:

- write `sport_plan.md` here: skills, drills, how each is measured, and the earliest rehab gate (Knot) each drill is allowed at;
- add the sport sessions to your weekly template where the plan has room;
- turn each skill into an **Art** in the saga (e.g., a passing skill becomes a named sword-art), gated the same way.

Until then, sport work you log still counts (XP, Finesse, Vigor); it just doesn't feed a named Art yet.
