# Sport add-on

- **`sport_plan.md`** — read first: the skills (the `skill` ids for `sport_log.csv`), the progression by rehab phase (seated or square now, the left-foot pivot from Phase 4), the week, solo setup (net, field), the first 12 weeks by the calendar, logging, reviews. `python3 engine/darrow.py doc sport <section>`.
- **`Ultimate_Offseason_Development_Guide.md`** — the guide as written (Oct 2026 → late spring 2027): the content of every session and week. `python3 engine/darrow.py doc sportguide "<words>"`.

Set up with `/sport` on 10/9. A new version of the guide replaces that file as written; `sport_plan.md` is then reviewed against it.
