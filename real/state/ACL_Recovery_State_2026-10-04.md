### Progression rules (full text: Working Rules, load rule 4; not in this repo yet)

- Every working set ends with 2–3 clean reps left (RPE 7–8) once that exercise has produced a clean morning at its current dose; new items and new loads start at 3–4 in reserve. Never to failure.
- Mechanics end the set before effort does: knee drifting in, hip dropping, rushed lowering.
- One change per exercise per session, made on the last set, only if earlier sets were clean. Several exercises can change on the same day.
- Load steps: one DB increment or ≤10%.
- One new exercise per session, bodyweight first. PT items run at PT dose don't count as new.
- A morning that isn't clean reverses every change from the previous session.
