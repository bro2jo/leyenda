# The Reforging (retired)

The first version of the game: a nutrition-only layer whose bosses, weapons and loot were built from food ("Kirk's Waybread", "Gristlemaw, the Unfed Hound"). It was replaced on 2026-10-08 by **The Unkneeling**, which keeps every real number on the Ledger side and lets the story stand on its own.

Kept for reference only. Nothing here is read by the engine.

- `game_rules.md`: the old rulebook
- `save_file.md`: the old save (Level 4, 940 XP as of 10/7). The new engine recomputed Darrow's start from the real logs instead: Level 4, 735 XP.
